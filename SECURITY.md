# Security

Report vulnerabilities privately through the [HeartPro support form](https://heartpro.alkinum.com/support/). Include the affected version or commit, impact and minimal reproduction steps using synthetic data. Do not include health records, passwords, API keys or signing material. Please avoid public issues for an unpatched vulnerability.

Security fixes are developed against the current `main` branch. Older commits and development builds do not have a separate maintenance guarantee. We will investigate reports, but do not promise a fixed response time.

For ordinary bugs or improvements, open a GitHub issue with the app version, device/OS version and reproduction steps. Review screenshots for private information before sharing.

# 逐段研究分析（0.6.0 更新）

本轮将「波段与参考范围」占位改为实际的逐搏估计、全记录分布和可定位的原波形复核。所有数值是研究结果，没有经过真实 Watch 独立标注验证；不生成医学正常／异常结论或疾病分类。

## 指标覆盖

| 模块 | 实际计算 | 不可评估的主要情况 |
| --- | --- | --- |
| P 波 | 起止／峰时间、时限、带符号振幅、正／负／双相形态候选 | 低幅、融合、多瓣分离、局部噪声、边界不清 |
| PR 间期 | 同搏 P 起点至 QRS 起点 | 缺少任一起点 |
| PR 段 | P 终点至 QRS 起点、相对 TP 基线的平均电位 | P 终点不清或短于 16 ms |
| QRS | 时限、Q／R／S 候选振幅、Q／S 分量时限、起点至 R 主峰 | 未回到低斜率、分量缺失、局部噪声；负向主峰保留原始极性，命名需复核 |
| ST／J | J 电位、ST 时限、J+60／80 ms 电位、60–80 ms 斜率 | T 起点不明、采样点落入 T 波、QRS 终点不清 |
| T 波 | 起止／峰、时限、振幅、极性、前／后半时限比 | 低幅、噪声、双瓣边界无法分离、截断、融合 |
| QT | 同搏 QRS 起点至 T 终点 | 任一边界缺失 |
| QTc | Fridericia、Bazett 两式，使用同搏 QT 和前一 RR | 前后 RR 不连续、不足或波动超过 10%，RR 不在 500–1500 ms |
| TP | 本搏 T 终点至下一搏 P 起点 | 区间 <40 ms、缺口、P／T 边界缺失 |
| RR／PP | 分别计算邻近 R 峰间距和 P 峰间距 | 前一搏缺失、P 峰不可辨认、信号不连续 |
| U 波 | 0.4 新增分离且重复的小波形候选；足够候选才展示 | 不缩短融合 T 波、不确认为临床 U 波；详见节律分析说明 |

每项指标分别汇总中位数、极值范围、P10–P90 和可测数／尝试分段搏数；范围是测量分布，不是正常范围或置信区间。尝试分段的分母来自研究性 R 检测器，漏检的心搏不会进入分母。整条记录的时间覆盖继续在「信号与覆盖」单独展示。

## 方法与支持窗口

- 不改变显示或保存的原波形。分析使用约 10 ms 的对称局部均值，并从安静的跨搏基线锚点估计慢漂移；ST 电位相对该基线测量，不使用 R 检测器的高通结果，也不把 ST 平台强制归零。
- 精细定位要求采样率 ≥200 Hz、相邻 RR 350–2000 ms；QTc 仍要求 RR 500–1500 ms 和原有稳定性条件。时间分辨率不是测量误差，所有窗口均是研究算法的支持条件。
- 基线搜索区为 R−min(440 ms, 0.48 RR) 至 R−min(280 ms, 0.32 RR)，滑动选择 25–60 ms 的安静片段。局部线性拟合去趋势后的残差极差 >0.045 mV、MAD 噪声 >0.012 mV 或斜率绝对值 >0.6 mV/s 时拒绝；不再把缓慢漂移直接当作高频噪声。以锚点电位和斜率做 Hermite 插值；无连续后锚点时仅使用当前锚点线性外推。长 PR／重叠 T 可能使基线假设失效，因此真实数据验证仍必需。
- 旧基线窗口在 100 bpm 时只剩 8 ms，在 120 bpm 时倒置，导致整搏被拒绝；0.6.0 修正了窗口两端的 RR 缩放。T 搜索终点也同步按下一 RR 缩放，避免截断可清楚分离的 T 波。
- QRS 采用相对主峰斜率与持续约 12 ms 的低斜率片段；P／T 采用峰值 10%／绝对下限的边界定义，非人工切线法。两种边界方法均可能产生系统误差。
- ST 位移存在时，T 起点可相对稳定 ST 平台寻找，T 终点仍相对 TP 候选基线；平台无法辨认则不强制给出 ST 数值。
- 所有跨搏统计检查原时间戳和信号质量；采样缺口不拼接。QTc 先逐搏计算，再汇总，不能用两个独立中位数相除。
- 细节页能浏览所有候选搏，包括未测出的搏；显示本段起止线、指标缺失原因、上一／下一搏及完整波形定位。原始局部图遇采样缺口断线。
- 0.6.0 原图顶部显示有完整实测边界的 P／QRS／T／U、PR 段／ST／TP、PR／QT、RR／PP。QTc 是校正数值，不伪造为原图上的区间；缺失边界不按模板补齐。全屏和内嵌视图共享缩放、滚动位置及手动测量状态。
- PDF 分页包含全部模块、指标分布、覆盖、拒绝原因和方法限制；逐搏交互保留在应用详情。

## 验证

核心采用与 DemoData 不同的分段线性夹具，预先给定 P／QRS／T 边界；检查 250／500／1000 Hz 的时间误差（各指标容差 2–32 ms）、振幅误差、极性／直流平移不变性、ST 正负偏移、P／T 缺失、低采样率、平线、基线噪声、局部 T 噪声、上升沿截断、跨窗口缺口、融合 T、QTc 公式及不稳定 RR、旧结果解码。

合成测试只覆盖指定波形及拒绝条件，不能给出真实 Watch 的准确率、灵敏度或临床适用性。真实 Watch 数据集、人工标注对照、广泛病理形态、真机 HealthKit 和不同采样／滤波来源仍未验证。

0.3.0 的 24 项核心测试及当时的 App／UI 验证见[旧验证记录](./validation/segments-0.3/README.md)。0.6.0 新增 100／120 bpm、慢漂移、漂移叠加正负 ST、顶部实测区间与缺口回归，当前结果见[0.6.0 验证记录](./validation/detail-0.6.0/README.md)。

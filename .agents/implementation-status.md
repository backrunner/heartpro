## 测试口径

报告与控件修订：4 项报告测试、3 项相关 UI 用例通过，涵盖六语导出、全时长波形、长备忘、圆形按钮尺寸、德语大字号和深色界面；543 个语言键检查通过。产物及口径见[本轮验证](./validation/report-design-0.4/README.md)。

0.4.0：35 项核心测试、7 项 App 测试与 5 项相关 UI 测试通过；覆盖六语流程和德语大字号。公开八条 MIT-BIH 记录中的早搏检出率为 43.78%，仍有大量漏检。完整口径与逐条数据见[本轮验证](./validation/rhythm-0.4/README.md)。

- 核心库使用 Swift Testing；存储／PDF 用 XCTest；界面用 XCUITest。
- 模拟器视觉检查与 UI 自动化不代表真机 HealthKit 读写验证。
- 固定 NN 数学公式测试不代表 ECG 上的正常搏动识别准确；合成 R 峰测试不代表临床准确率。
- 此版本未宣称完成任何真实 Watch 数据集、所有负载或医学用途验证。

0.1.0 的 8 项核心测试和 5 项存储／PDF／UI 测试全部通过；该记录不代表 0.2.0 新功能已验证。最终运行结果、截图与命令见[首版验证报告](./validation/2026-09-17-development-preview.md)。

0.2.0：12 项核心测试通过，9 个 App 用例均取得通过结果（完整运行加定向复测）；修复了测试控件标识与截图接口等待问题。见[本轮验证与界面截图](./validation/refinement-0.2/README.md)。

0.3.0：24 项核心测试和最终 6 项 App 定向测试通过；本轮其余 4 项原有 UI 用例在前次全量运行通过。逐段分析已接入核心、详情与 PDF；具体能力和验证范围见[逐段分析说明](./segment-analysis.md)。

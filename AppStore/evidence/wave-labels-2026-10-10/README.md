# 波形标签修复验证

2026-10-10，HeartPro 0.6.0 (1)。合成示例，无真实健康数据。

问题：标注文字只有在其宽度小于实测波段色块时才绘制，窄 QRS 因此留下空色块。缩放时，默认居中的标注容器还会被 LazyHStack 的宽度估计推离波形时间原点。

修复：文字宽度独立于时间范围，所有标注保留完整标签；拥挤标签分行并以引线连接原范围。测量边界和原始波形不改变。文字最后绘制，防止被相邻色块覆盖；文字本身也可点击选中。标注与波形均从同一个水平原点和相同内容宽度布局，缩放后保持对齐。标注字号跟随 Dynamic Type。

验证：

- 通过：3 项 WaveformBandTests，覆盖窄 QRS 全文/点击范围、0.5–6 倍缩放与 9/18/28 pt 的密集标签不重叠、精确时间边界、两端截取及空输入。
- 通过：iPhone 两项 UI 流程，普通浅色、0.5 倍、深色大字号、QRS 点击读数，以及自动横屏全屏/关闭后缩放状态保留。截图已目视确认全标签及时间位置。
- 通过：iPad 两项 UI 流程及实际截图，浅色/深色大字号、最小缩放、QRS 点击及手动横屏全屏/返回竖屏均已验证。iPad 窗口可能拒绝应用请求的自动旋转，测试使用设备方向切换检查横屏全屏与返回竖屏；不把手动方向验证写成自动旋转通过。
- 六语覆盖/占位符校验通过；没有新增显示文案或改动算法。
